# Weather App (Open-Meteo)
Weather project using the free [Open-Meteo API](https://open-meteo.com). No API key needed.

 1. Python script
   weather.py - shows current weather and a 3-day forecast for a city.

 2. Map dashboard: HTML, CSS, JS
    Folder: weather-map html -
    Tap anywhere on the map to see the weather of that place in a popup (Leaflet.js).
    To run: open the folder in VS Code and use the Live Server extension on 'index.html'.

 3. Map dashboard: React -
    Folder: react version
    Same feature built with React and react-leaflet.
    
    ```
       cd "react version"
       npm install
       npm run dev
    ```
    Then open http://localhost:5173
